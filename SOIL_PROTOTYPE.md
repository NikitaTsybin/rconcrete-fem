# Прототип расчёта основания Rconcrete FEM

## Текущий результат

Рабочий исследовательский прототип выполнен на `8 этажей для посадки на грунт.zip`, опорный режим **Сочетание1 / Нормативные длительные**. Исходный файл не изменялся. Итог: `dist/soil_prototype/building8/building_on_soil.slab.zip`, численные данные и карты — рядом.

- МКЭ500мм; грунтовые ячейки1000мм,428активных ячеек.
- Одно основание,3287внутренних точек в центрах физических КЭ, отдельные значения на внешней границе.
- C1 после сходимости фиксируется. Обычный МКЭ-расчёт полученного проекта не вызывает грунтовую итерацию снова.
- Продолжение из предыдущего приближения:28итераций,499.91с расчёта с сохранением; полный запуск502.05с. Это **не время холодного старта**: ранее выполнены40итераций с более консервативным обновлением. История этапов — `building8/stages.json`.
- Последняя относительная невязка C1:1.9769% при критерии2%.
- Интегральные осадки МКЭ и грунта: среднее расхождение0.1151%, максимальное2.0167%. Критерий использует max(C_old,C_target) в знаменателе; поэтому2% по C1 допускают до2.0408% по отношению осадок.
- Осадки грунта23.173…39.196мм; МКЭ23.176…39.199мм. Отдельно сохранено приближённое усреднение узловых осадок (`fe_nodal_proxy_m`), оно также проверено.
- Передаваемая сила5196.6019стандартных тс, то есть50961.2561кН. Невязка вертикального баланса−0.004495кН.
- Глубина сжимаемой толщи по принятому прототипному критерию8.134…13.635м; ни одна ячейка не достигла предела16м.
- Площадь чистой нижней плиты409.08м²; сумма переданных площадей КЭ409.0800000000001м².
- Повторный запуск с зафиксированным C1 подтвердил сходимость за одну итерацию. Максимальное изменение C1≈2.3e−13.
- Диапазон C1:121.31…5044.41тс/м³; давление4.665…176.542тс/м². Локальные пики давления явно сохранены. Несущая способность грунта, пластичность и допустимость таких пиков **не проверялись**.

Это прототип, не утверждённый проектный расчёт. Геопривязка и методика требуют инженерного подтверждения.

## Принятые исходные данные

Грунт — оригинальный `S1-2 S11 (отдельно).sld`, ранее расшифрованный и сверенный с таблицей пользователя:60скважин,25ИГЭ. Компактная выгрузка `ground_reference.json` содержит скважины и исходные свойства; нагрузки из SLD не используются. Нагрузки берутся из схемы здания.

Временная геопривязка: центр **габарита** здания(13.7,8)м соответствует точке грунта(10,0)м; XY-смещение−3.7,−8м. Подошва принята на абсолютной отметке144.5м. Координаты исходной геометрии здания не менялись. Эти допущения не были подтверждены пользователем и вынесены для обсуждения.

Исходная нижняя плита600мм сохранена. Автоматическое закрепление низаXYZ заменено наXY; верхнее автоматическое закрепление выключено. Основание назначено только плите16 нижнего этажа. Горизонтальное закрепление — временный способ стабилизации для этого вертикального расчёта, не определённая модель горизонтальной податливости грунта.

## Алгоритм и единицы

`src/soil.rs` — независимое Rust-ядро, без egui/wgpu:

1. Дополнительные вертикальные напряжения Буссинеска от прямоугольных источников. Использовано угловое выражение интеграла по площади, а не точечный источник в собственной ячейке.
2. На каждой абсолютной отметке: три ближайшие скважины, IDW по обратному квадрату расстояния, интерполяция податливости1/E. За пределы глубины профиля молчаливое продолжение слоя не выполняется.
3. Послойное суммирование `ds=beta*sigma/E*dz`, beta=0.8. Это принятая модель послойного суммирования, не точное решение слоистого упругого полупространства. nu, c, phi и неизвестные поздние поля SLD не используются как подменные параметры.
4. Глубина ограничена max_depth и отношением дополнительного напряжения к весу грунта **ниже подошвы**0.2. Пересечение критерия интерполируется внутри шага. Бытовое давление выше подошвы, разгрузка от выемки, вода/взвешивание, консолидация и ползучесть пока не моделируются.
5. `C1=q/s`, релаксация, повторный штатный МКЭ-расчёт. Итоговая конфигурация:релаксация0.8,допуск0.02,предел80итераций,шаг глубины0.25м,max_depth16м.
6. C1 записывается в центры физических КЭ. Q4 использует один центр для двух отображающих T3. Давления и площади этих T3 не считаются дважды как две физические нагрузки.
7. Ячейки получают сумму площадей и сил присвоенных по центру КЭ. `coverage` — **эффективный коэффициент площади**, может превышать1 из-за присвоения центров; это не точная геометрическая доля пересечения. В грунтовом ядре эквивалентная прямоугольная интенсивность равна q*coverage, что сохраняет силу. Точные пересечения площадей и дальнейшее сгущение — следующий уровень уточнения.
8. Интегральная осадка МКЭ берётся из согласованной реакции пружины q/C1. Дополнительно записано независимое приближённое усреднение по узлам. Это различие показано явно для Q4.

Внутренние единицы грунта:m,стандартные тс,тс/м²,тс/м³. Соответствие E/gamma/c из данного SLD подтверждено таблицей пользователя и множителем0.00980665; это не утверждение об универсальном формате всех версий SLD. Offset52 — коэффициент второго модуля, не R0.

Стандартная тонна силы=9.80665кН. Проект использует настраиваемое g. Сохранённый C1 в единицах приложения равен C1_standard*9.80665/g; преобразование обратно в кН точно восстанавливает физическую жёсткость. Для сравнения результатов удобны кН. Оболочечная пружина имеет глобальный Z-знак; адаптер принимает давление сжатия `−foundation_pressure_kn_m2/9.80665`.

Отрицательное среднее давление опорного сочетания вызывает ошибку о необходимости одностороннего контакта. Односторонний контакт пока не реализован. Нулевые давления сохраняют прежний C1; они не утверждают нулевую осадку от соседних нагрузок.

## Встраивание и повторный запуск

`Engine::iterate(initial_c1, solve)` принимает callback `solve(C1)->pressure` и возвращает converged,C1,давления,осадки,историю. Отдельный адаптер `src/plan_trace/soil_prototype_host.rs` использует штатный решатель здания, общее разложение для загружений и суммирование выбранного сочетания. Сетка стен предварительно вычисляется один раз. На каждом наборе C1 считаются все реальные загружения, затем извлекается опорное сочетание. После фиксации C1 другие сочетания — линейные расчёты на том же основании, не точная универсальная нелокальная модель грунта.

В автоматический цикл GUI грунтовый расчёт **пока не подключён**. Результирующий проект открывается и считается обычным способом; математическое ядро готово для переноса в job/worker интерфейса.

```text
slab_contours.exe --soil-prototype project.zip ground.json output_folder mesh_mm ground_step_mm warm_report.json options.json
```

Последние параметры необязательны. Для options.json без warm-report используется `-` на его месте. JSON содержит все поля Options; `soil_config.json` — готовый пример. В отчёте `options` — фактические параметры.

Python-обёртка требует только стандартную библиотеку:

```text
python soil_prototype/run.py soil_prototype/building8_source.zip --output soil_prototype/results --mesh 500 --ground-step 1000 --warm soil_prototype/building8/report.json --config soil_prototype/soil_config.json
python soil_prototype/report.py soil_prototype/results/report.json
```

Обёртка сохраняет журнал, SHA исходников, конфигурацию, время и код завершения. Несходимость даёт отдельный неуспешный статус. Ctrl+C завершает дочерний расчёт. Старый отчёт в той же папке не считать новым после неуспешного запуска.

Для повторного прототипа используйте **исходный** проект и warm-report, не уже обработанную копию с основанием: автоматическая замена прежних контуров в CLI пока не предусмотрена.

Кэш неизменных коэффициентов влияния ограничен64МиБ коэффициентов f32; суммирование и решение выполняются вf64. После лимита используется потоковый путь. Это не обещание приемлемой скорости для тысяч ячеек: сложность поточного пути O(N²*Nz). Кэш проверен относительно прямого вычисления на разных давлениях. Контрольная жёсткая плита400ячеек/60итераций заняла3.404с с тем же результатом; строгая сходимость0.5% в том контроле не достигнута и не выдаётся за успех.
