# Памятка по Rconcrete FEM

## Где работать

- EXE `slab_contours` запускается из `src/bin/slab_contours.rs`. Общий интерфейс и модель находятся в `src/plan_trace`, веб-вход — в `fem_web/src/lib.rs`.
- Геометрия, этажи и формирование сетки — `model.rs`, `building.rs`, `building_mesh.rs`, `meshing.rs`. Расчёт — `src/plan_trace/fem`. Отрисовка 3D — `spatial_ui.rs`, `spatial_world.rs`, `spatial_depth.rs`.
- Импорт ЛИРА — `lir_import.rs` и локальный Rust-парсер в `extra/lir_asp_rust`. Matrix Grid вынесен в `C:/web/grid`.
- Согласованное управление и правила изменений описаны в [AGENTS.md](AGENTS.md).

## Что учитывать при изменениях

- Модель, идентификаторы объектов и расчётная сетка должны быть независимы от графических примитивов. Скрытие и фрагментация действуют на вид и выбор. При работе с результатами проверяйте активное загружение или сочетание, этаж и видимость.
- Сохранённые проекты `.slab.zip` содержат исходные данные. Сетка и результаты строятся заново. Новые поля модели должны иметь совместимые значения по умолчанию для старых проектов. В вебе проекты OPFS привязаны к адресу сайта, включая порт.
- Веб использует wgpu с WebGPU и резервным WebGL2 (`?graphics=webgl2`). Основное приложение загружается из `pkg`, Solver Worker может использовать `pkg_parallel` при включённой конфигурации и COOP/COEP.
- Силы можно задать по X/Y/Z. Положительное значение по Z направлено вниз. Положительный момент задаётся по правилу правой руки и прикладывается к узлу КЭ на фактической отметке. Линейные и площадные силы привязаны к плоскости плиты. Экспорт горизонтальных сил и моментов в ЛИРА и PLAXIS пока недоступен.

## Сборка и проверки

- Windows: `cargo build --locked --release --bin slab_contours`. Графическая проверка: `cargo run --bin slab_contours -- --smoke-test --smoke-3d`.
- Локальный веб: `scripts/build-fem-web.ps1` собирает обычный и многопоточный WASM и серверный ZIP. В уже запущенном локальном сервере обновление файлов применяется после перезагрузки страницы. Для отдельного запуска сервера используйте `python scripts/serve-fem-web.py --port 8766`.
- Типовая проверка кода: `cargo fmt --all --check` и `cargo test --locked --bin slab_contours`.
