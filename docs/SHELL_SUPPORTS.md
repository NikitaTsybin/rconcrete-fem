# Пространственные опоры — пилотная реализация

Сборка от29.10.2026 включает эту ветвь. Выполнены patch/rigid-translation,
балансы, вес стен, сочетания, проверки трёх направлений и реального Проект2;
смешанная DKT/MITC4-плита сравнена с аналитическим решением Навье. Полный
набор произвольных пространственных задач не верифицирован; это пилот.

## Исходные данные и геометрия

Справа: «Учитывать высоту опор», «Вверх / Вниз / Вверх+вниз», высота в мм.
Материалы задаются в левом экспандере «Жёсткости». Контур опоры выбирает
именованный набор: h, E, ν (200 мм, 30000 МПа, 0.2 у «Стена 1»), вес по
умолчанию 0. Общий набор можно назначить нескольким контурам.
Начальная высота 3000 мм. При «Вверх+вниз» она откладывается в каждую сторону.
Параметры сохраняются в проекте, но производная пространственная сетка — нет.

Стенки строятся по согласованным рёбрам исходной опоры, а не по её площади.
Узлы на пересечении опор и на стыке с плитой общие. Разбиение по высоте
равномерное, число слоёв ceil(H / размера КЭ). Совпадающие стенки не дублируют
жёсткость; разные материалы у полностью совпадающих стенок вызывают ошибку.

Нижние узлы всего вытянутого контура закреплены по X,Y,Z, верхние — по X,Y.
Повороты свободны. При направлении «Вверх» низ находится на уровне плиты;
при «Вниз» на уровне плиты находится верх. Исходное w=0 по опорам заменяется
этими пространственными закреплениями. При выключенном учёте высоты остаётся
прежняя плоская постановка.

## Оболочечная сборка

`fem/shell.rs`: три глобальных перемещения и физический вектор поворотов.
В одной плоскости хранятся только два касательных поворота. На стыке разных
плоскостей — три. Свободная нормальная drilling-ротация не получает пружин
или фиктивной жёсткости. Локальные наклоны p_x=-θ_y, p_y=θ_x.

Мембранная матрица: плоское напряжённое состояние, Dm=Eh/(1−ν²).
Треугольник — CST, четырёхугольник — изопараметрический Q1 с 2×2 Gauss.
Изгиб: исходный DKT для треугольника; настоящий MITC4 для Q4.
Матрица оболочки — преобразование обеих физических матриц в общие XYZ DOF.
Разреженная сборка, диагональное масштабирование, faer Cholesky LL^T.

### Ограничение P2/CR

По последнему указанию пользователя сопряжение P2/CR с MITC4 отложено.
P2/CR сохраняется в прежней реализации только для плоской треугольной сетки.
При наличии четырёхугольников выбор блокируется в UI и отвергается ядром.
Высота опор также требует DKT/MITC4, потому что вертикальные стенки Q4.
Промежуточные DOF P2/CR не исключаются и не связываются средними значениями.
Возвращаться к смешанной постановке планируется после четырёхугольников
с промежуточными узлами; их сопряжение и численная верификация — отдельная работа.

## Нагрузки, реакции, результаты

Нагрузка передаётся в глобальном направлении −Z. Сосредоточенная — через
функции формы в своей фактической точке; линейная — набор точек с шагом КЭ.
Любое положительное перекрытие площадной нагрузки активирует полное q на
физическом элементе. Тесселяционные треугольники Q4 не дублируют нагрузку.
Собственный вес включает вертикальные стенки, если в их жёсткости задан
ненулевой вес. У стен он по умолчанию 0, у плит — 2.75 тс/м³.
Источник линейной/площадной нагрузки сохраняется исходным контуром.

Реакции пересечений делятся между опорами поровну. В 2D реакции
нижних узлов проецируются на исходные плановые узлы; суммарные реакции
опор хранятся отдельно. Это не физическое закрепление узла плиты.

Добавлены результаты U,V в мм и Nx,Ny,Nxy в силовых единицах/м. Локальные
тензоры плит преобразуются в глобальные X,Y. Для пространственных сочетаний
комбинируются перемещения, мембранные усилия и реакции опор. Шкалы U/V
не пересчитываются при смене силовых единиц; старые файлы дополняют шкалы.

3D — исходная недеформированная сетка, просмотр без выбора/изменения объектов.
ПКМ вращение, СКМ панорама, колесо масштаб, двойной щелчок вписать.
Требуется построенная сетка. Нет отрисовки деформированной схемы или изополей
по вертикальным стенкам. Текущие изополя результатов остаются в 2D плиты.

## Очередь проверок

- fmt/check/build, полный набор старых тестов и сохранение старых проектов.
- Точный Проект2.slab.zip: численные грани и цепочки опор до/после quad optimise.
- Patch/rigid body, отсутствие drilling-null DOF, вертикальные/наклонные стенки.
- Все три направления высоты, отдельные материалы, общие узлы, дубли стенок.
- DKT/MITC4-оболочки, прежняя плоская P2/CR и запрет P2/CR+Q4/высоты.
- Сходимость DKT/MITC4, тонкая плита, изгиб/мембрана стенки,
  независимость от ориентации локальных осей и графической диагонали.
- Баланс трёх сил и моментов, точечные/линейные/площадные нагрузки,
  собственный вес, пересечения опор, сочетания и единицы.
- Большая модель, 3D-проекция, панорама/вращение/масштаб, пустая сцена,
  отключение всех графических изменений и клавиатурных команд в 3D.

Исходные формулы оболочки: [SesamX — shell finite element](https://www.sesamx.io/blog/shell_finite_element/).
Изгибная часть MITC4 описана отдельно в [MITC4.md](MITC4.md).
