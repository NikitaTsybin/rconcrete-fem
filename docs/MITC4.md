# Четырёхузловой элемент плиты MITC4

Статус: новая реализация в исходниках. Проверки и сборка ожидают команды
пользователя. До выполнения тестов эта ветвь не считается проверенной.

Формулировка: [Bathe, Dvorkin, 1985](https://onlinelibrary.wiley.com/doi/10.1002/nme.1620210213).
Теория смешанной интерполяции: [публикация авторов на сайте MIT](https://web.mit.edu/kjb/www/Publications_Prior_to_1998/Displacement_and_Stress_Convergence_of_the_MITC_Plate_Bending_Elements.pdf).
Код написан в проекте самостоятельно; новая сторонняя библиотека не подключается.

В узле три степени свободы: \(w,p_x,p_y\), где повороты записаны как наклоны
нормали. Координаты результатов — глобальные XY. В ядре единицы м и кН.

Для узлов \((r_i,s_i)=(-1,-1),(1,-1),(1,1),(-1,1)\):

\[
N_i(r,s)=\tfrac14(1+r_i r)(1+s_i s),\quad
x=\sum N_i x_i,\quad y=\sum N_i y_i,\quad
w=\sum N_i w_i,\quad p=\sum N_i p_i.
\]

Якобиан вычисляется в каждой точке. Его положительность проверяется в углах и
точках Гаусса; обратное отображение для сосредоточенной нагрузки — методом Ньютона.
Кривизны: \((p_{x,x},p_{y,y},p_{x,y}+p_{y,x})\). Матрица изгиба:

\[
D_b=\frac{Eh^3}{12(1-\nu^2)}
\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&(1-\nu)/2\end{bmatrix}.
\]

Поперечный сдвиг — \(\gamma=\nabla w-p\). MITC4 использует ковариантные
компоненты в серединах сторон:

\[
g_r(r,s)=\tfrac12[(1-s)g_r(0,-1)+(1+s)g_r(0,1)],
\]
\[
g_s(r,s)=\tfrac12[(1-r)g_s(-1,0)+(1+r)g_s(1,0)].
\]

Они переводятся в глобальные компоненты через обратный текущий якобиан.
Используется \(D_s=(5/6)Gh I_2\). Собственная матрица 12×12:

\[
K_e=\int_{-1}^1\int_{-1}^1
(B_b^T D_b B_b+B_s^T D_s B_s)\det J\,dr\,ds.
\]

Обе части интегрируются схемой Гаусса 2×2. Штрафные добавки и искусственная
жёсткость для устранения вырожденности не применяются.

Равномерная нагрузка: \(f_{wi}=q\int N_i\det J\,dr\,ds\). Точечная нагрузка:
\(f_{wi}=P N_i(r_P,s_P)\). Линейная разбивается на сосредоточенные нагрузки с
заданным шагом и теми же функциями формы. По согласованному правилу положительное
пересечение области нагрузки активирует полное \(q\) на всём физическом КЭ.
Собственный вес интегрируется один раз на четырёхугольник.

Усилия в центре: \(M=-D_b B_b q_e\), \(Q=D_s B_s q_e\).
Перемещения и подсказка на курсоре используют билинейную интерполяцию Q4.

Расчётный четырёхугольник хранит четыре узла и свой ID. Ссылки на две исходные
треугольные области служат поиску по геометрии и отображению результата.
Эти области не добавляют жёсткости, нагрузок или степеней свободы.
Треугольники, которые не объединены, рассчитываются DKT.

Смешанная матрица собирается разреженно и решается существующим Cholesky LLᵀ.
Закрепляется только \(w\) узлов контуров опор. Режим P2/CR пока разрешён только
для треугольной сетки: его краевые степени свободы не подменяются узловыми MITC4.

отображение, равнодействующая и моменты нагрузок, жёсткие движения, constant

решения от графической диагонали, баланс трёх типов нагрузок.
