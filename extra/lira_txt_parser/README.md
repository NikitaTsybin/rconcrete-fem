# Парсер геометрии TXT ЛИРА-САПР

Самостоятельная Rust-библиотека, без exe, GUI, egui, wgpu и зависимости от Mini FEM.
`src/lib.rs` — копия работающего `src/lira.rs` Mini FEM на 21.10.2026.
Единственная внешняя зависимость — `encoding_rs` для кодировок. Все исходники и тесты в пакете.

## Подключение

Скопируйте папку целиком. В Cargo.toml принимающего проекта:

```toml
[dependencies]
lira_txt_parser = { path = "../lira_txt_parser" }
```

```rust
use lira_txt_parser::{read, parse};
use std::path::Path;

fn main() -> Result<(), String> {
let geometry = read(Path::new("scheme.txt"))?;
for node in &geometry.nodes {
    println!("node {}: {:?}", node.id, node.xyz);
}
for element in &geometry.elements {
    println!("element {}, type {}, stiffness {}, nodes {:?}",
        element.id, element.fe_type, element.stiffness, element.nodes);
}
// Альтернатива: parse(&decoded_text) -> Result<Geometry, String>.
Ok(())
}
```

`read(&Path)` читает UTF-8 (включая BOM), UTF-16LE/BE с BOM, иначе Windows-1251.
`parse(&str)` принимает уже декодированный текст. Ошибки возвращаются строкой на русском.
Для браузера передавайте текст через parse; файловый read предназначен для файловой системы.

## Контракт для другого агента

- Документ `(4/ ... )`: узлы, записи `X Y Z /`. ID — порядковый номер записи с1, а не первое поле.
- Документ `(1/ ... )`: элементы, записи `тип_КЭ номер_жёсткости узлы... /`. ID — порядок записи с1.
- Разделитель записей `/`, перенос строки НЕ разделитель. Запись может занимать несколько строк.
- Node { id: usize, xyz: [f64;3] }; Topology { id: usize, fe_type: u32, stiffness: usize, nodes: Vec<usize> }.
- Geometry { nodes, elements, skipped: BTreeMap<тип, количество>, documents: Vec<номер> }.
- Ссылки nodes в элементе — исходные ID с1, не нулевые индексы. Для этого последовательного формата узел можно получить `geometry.nodes[id-1]`.
- Совпадающие XYZ не объединять, ID не перенумеровывать; при пропуске неподдержанного типа ID следующего элемента сохраняется.
- Поддержаны двухузловые КЭ1–10, оболочки42(3узла)/44(4узла), точечный56(1узел). КЭ56 не считать стержнем.
- Для КЭ44 исходная связность1,2,3,4 сохранена. Только для обхода/рисования использовать позиции0,1,3,2 (узлы1,2,4,3).
- Единицы и оси не преобразуются, XYZ остаются f64. Номер жёсткости — только ссылка, не расчётные свойства.
- Неизвестные типы пропускаются с отчётом skipped; ссылки на отсутствующие/нулевые узлы проверяются даже у неизвестных типов.
- Нагрузки, результаты, связи, жёсткие вставки, локальные оси, этажи НЕ импортируются.
- Поддержан развёрнутый последовательный язык. Сжатые операторы, пустые/удалённые записи, повторные документы, комментарии внутри числовых записей и явная произвольная нумерация не поддержаны.
- Это подмножество ЛИРА-САПР, не универсальный парсер всех продуктов/версий. Весь файл загружается в память.
- Подробности и ссылки на ранее изученную официальную справку — FORMAT.md. Документ адаптирован для самостоятельной поставки.
