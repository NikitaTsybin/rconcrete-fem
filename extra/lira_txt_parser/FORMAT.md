# Геометрия текстового файла ЛИРА-САПР

Проверено 15.10.2026 по установленной официальной справке **ЛИРА-САПР 2024** и предоставленному файлу схемы. Это описание поддержанного подмножества, а не полная спецификация всех версий входного языка.

## Где искать документацию

На этом компьютере:

`C:\Program Files (x86)\LIRA SAPR\LIRA SAPR 2024\Bin\help\ru\LiraSapr.chm`

Разделы внутри справки:

- «Сводный список документов исходных данных (сокращенно)» — `Explain/_EXPL_TABL_DOC.htm`.
- «Создание задачи из текстового файла исходных данных» — `Mode_Model/HIDD_IMPORT_TXT.htm`, актуальный список разделов.
- «КЭ 10», «КЭ 42», «КЭ 44», «КЭ 56» — `Explain/_FE_LIB_10.htm`, `_FE_LIB_42.htm`, `_FE_LIB_44.htm`, `_FE_LIB_56.htm`.
- Схема нумерации КЭ-44 — `image/FE_44.png`.

Для исследования справка распакована в игнорируемый `target/lira_help/`. Эти временные файлы не являются зависимостью приложения. Официальное онлайн-описание одноузлового КЭ-56 также есть в [обзоре ЛИРА-САПР 2015](https://www.liraland.ua/news/update/2452/). Не следует автоматически применять спецификацию другого продукта «ПК ЛИРА 10.x» ко всем версиям ЛИРА-САПР.

## Разделители

Документ имеет вид `( номер / содержимое )`. Запись завершается `/`. Пробелы и переносы строк разделяют поля, но **строка не равна записи**: несколько записей могут идти в одной строке, а запись — занимать несколько строк.

В развёрнутых документах 1 и 4 номера элементов и узлов определяются порядком записей, начиная с 1. Первое поле документа 1 — тип КЭ, а не его номер. Первое поле документа 4 — координата X, а не номер узла.

## Основные документы

| Номер | Содержимое | Импорт Mini FEM |
|---|---|---|
| 0 | Заглавный документ и настройки; вложенные подразделы, например 0.33 — единицы измерения | Не интерпретируется |
| 1 | Элементы: тип КЭ, номер жёсткости, номера узлов | Да |
| 2 | Шарниры | Нет |
| 3 | Жёсткостные характеристики | Нет; ссылка на жёсткость из документа 1 сохраняется |
| 4 | Координаты узлов XYZ | Да |
| 5 | Связи и группы объединения перемещений | Нет |
| 6 | Типы/приложение нагрузок | Нет |
| 7 | Величины нагрузок | Нет |
| 8 | РСУ | Нет |
| 9 | Углы согласования местных осей | Нет |
| 14 | Жёсткие вставки | Нет |
| 17 | Ортотропия, углы поворота стержней и некоторые местные системы координат | Нет |
| 19 | Коэффициенты упругого основания | Нет |
| 25 | Абсолютно жёсткие тела | Нет |

Таким образом, импортируется исходная геометрия узлов, без пересчёта осей, жёстких вставок, деформаций и конструктивных свойств. Другие документы не выполняются и не трактуются как инструкции приложению.

## Документ 4 — узлы

```text
(4/
0 0 0 / 4 0 0 /
0 4 0 / 4 4 0 /
)
```

Получаются узлы 1–4. Исходные координаты хранятся как `f64`. Совпадающие координаты не означают один узел: исходная идентичность и связность сохраняются. Парсер не создаёт графические примитивы и не изменяет исходные XYZ.

Единицы не угадываются и не пересчитываются: координаты и габариты показываются в единицах файла. В исследуемом файле подраздел 0.33 содержит `M 1 CM 100 T 1 C 1`.

## Документ 1 — элементы

```text
(1/
10 2 1 2 /
42 5 1 2 3 /
44 5 1 2 3 4 /
56 7 1 /
)
```

Элемент 1: тип 10, жёсткость 2, узлы 1 и 2. Элемент 2: треугольная оболочка 42. Элемент 3: четырёхугольная оболочка 44. Элемент 4: одноузловой специальный КЭ-56, отображается крестиком и сохраняет исходный тип; это не стержень и не оболочка.

Для **КЭ-44 исходная нумерация 1,2,3,4 не является обходом периметра**. По схеме в официальной справке обход для отрисовки: **1,2,4,3**. Исходная связность в данных остаётся неизменной. Плиты и стены различаются в просмотрщике по ориентации нормали, а не по типу 42/44: оба типа допускают произвольное положение в пространстве.

Поддержаны двухузловые типы 1–10, оболочки 42/44 и точечный 56. Неизвестные типы пропускаются с явным счётчиком по типам, исходные номера последующих элементов сохраняются. Недостающие ссылки на узлы, неверное количество полей и некорректные координаты вызывают ошибку; прежняя модель остаётся доступной.

## Ограничения первой версии

Поддерживается развёрнутая последовательная запись геометрии. Сжатые операторы входного языка, комментарии внутри числовых записей, произвольная явная нумерация, удалённые пустые записи и повторяющиеся составные документы не поддержаны: импорт выдаёт ошибку вместо догадок. UTF-8, UTF-16 с BOM и Windows-1251 распознаются. Только геометрия: нет нагрузок, расчётных жёсткостей, результатов, АЖТ и расчётного смысла КЭ-56. Фильтр этажей демонстрационной модели после импорта отключён — этажи из документа 4 достоверно не следуют.
