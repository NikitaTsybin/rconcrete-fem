# Пилот ML → НДМ для плит

Поставленные пользователем модели встроены в приложение; Python для работы не требуется. Исходные блокноты сохранены без изменения в source/. Контрольные суммы весов — manifest.json. Эталоны reference.json, ndm_reference.json и crack_reference.json получены из NumPy/функций исходных блокнотов и проверяются Rust-тестами.

## Единицы и модели

Сечение шириной 1000 мм. N — кН/м, растяжение положительно; M — кН·м/м, положительный момент растягивает нижнюю грань. Размеры — мм, напряжения — МПа, площади каждого слоя — см²/м.

strength.npz: SiLU MLP 17→192→192→192→2, стандартизация входов, экспоненциальное восстановление площадей двух слоёв. Область обучения: h=140–1000 мм, привязки 15 мм…0.45h, площади 0.5–200 см²/м. За пределами геометрической области используется механическое начальное приближение, затем НДМ.

crack.npz: SiLU MLP 22→188→188→188→9. Содержит прогноз границ образования трещин, напряжений обоих слоёв при образовании и полной нормативной нагрузке, события. Напряжения полной нагрузки используются только как начальное приближение независимого решателя; граница и напряжения проверяются НДМ. Область обучения h=150–1000 мм. Отказ модели не заменяет проверку механики.

## Подбор

Все расчётные и расчётные длительные сочетания проверяются в направлениях 0…170° через 10°. Проецируются N и M с учётом Nxy/Mxy, площади ортогональной сетки — Asx cos²θ + Asy sin²θ. Предложение ML формирует ограничения линейной задачи минимизации Asx+Asy отдельно для двух слоёв. Для длительных расчётных Rb умножается на 0.9 как в ML, так и в проверке НДМ. Проходы по всей модели разделены на ML, НДМ прочность и НДМ трещины, с отдельными временами. Затем каждое направление/сочетание проверяется НДМ с фактическими привязками; при необходимости площади растут. Каждое пробное значение площади округляется вверх до 0.01 см²/м перед проверкой; публикуются именно проверенные площади. Увеличение выполняется только для КЭ, который не прошёл проверку.

НДМ интегрирует кусочно-линейные диаграммы бетона аналитически, учитывает вытесненный арматурой бетон, Rs/Rsc и предельные деформации. Равновесие: Newton с аналитическим якобианом, начальным состоянием соседнего угла и ленивым перебором дополнительных начальных состояний; резервный вложенный поиск бисекцией. Успех ML не считается доказательством прочности. Ошибки содержат ID физического КЭ, не ID графического треугольника Q4.

При образовании трещин независимо ищется минимальный положительный множитель нормативного луча нагрузки. Напряжения арматуры после образования и при полной нагрузке вычисляются раздельно. Ширина: φ1 φ2 φ3 ψs σs/Es ls; φ2=0.5 (периодический профиль), φ3=1.2 при растяжении, иначе 1; ψs=1−0.8σs,crc/σs; ls=0.5 Abt/As d с границами СП. Длительное раскрытие: 1.4 a(norm.long). Кратковременное при совместном действии: a(norm.full)+0.4 a(norm.long). Выводится огибающая по слоям, углам и сочетаниям.

Неподтверждённый расчёт показывается красным, без фиктивного нулевого результата. Прочность и трещины имеют отдельные статусы. Арматура подбирается по прочности; автоматическое увеличение по допустимой ширине трещин пока не предусмотрено.

## Ограничения пилота

Только плиты, B15…B60 и A400/A500, изотропный бетон и арматура периодического профиля. Минимальный процент задаётся на каждый слой/направление от полной толщины. Расчётный диаметр для ls задаётся отдельно; фактическая раскладка стержней отсутствует. Не выполняются проверки поперечной силы, продавливания, анкеровки, конструктивных требований и ползучести с длительным модулем. Результаты подбора не сохраняются: сохраняются исходные параметры жесткостей. Параметры RC не меняют модуль E расчётной КЭ-модели автоматически.

При изучении исходного crack-блокнота обнаружено переиспользование kr как верхней границы сканирования и как найденного корня в rc_boundary_min_lambda. В Rust граница неизменна; добавлен тест симметрии положительного/отрицательного момента. Исходные веса и блокноты не исправлялись; поэтому предсказание ML само по себе не принимается за подтверждение.
