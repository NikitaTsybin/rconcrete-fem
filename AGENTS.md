# Работа агента в Mini FEM

Перед изменениями прочитай `HANDOFF.md` и `README.md`, затем проверь актуальный код. Записка описывает состояние проекта, но код и новые указания пользователя имеют приоритет.

После содержательных изменений обновляй `HANDOFF.md`: устройство приложения, согласованное поведение, ограничения, проверки и последнюю запись в журнале. Обновляй `README.md`, если изменилось управление или запуск. Не заявляй о проверках, которые не выполнялись.

Сохраняй согласованное управление: ЛКМ — рамка/выбор; ПКМ с движением — вращение; правый щелчок — меню; зажатое колесо — панорамирование; колесо — масштаб; Shift — добавить; Ctrl — убрать; Esc — сбросить выделение и отменить рамку. Щелчок ЛКМ в пустоту не сбрасывает выделение. Скрытые и отфильтрованные элементы не участвуют в выборе.

Согласованный стек — Rust, egui/eframe и wgpu. Изменение графического стека согласовывай с пользователем. Расчётную модель и её ID сохраняй независимо от графических примитивов.

Для изменений кода используй подходящие проверки: `cargo fmt --check`, `cargo test`, `cargo build`. При изменениях рендеринга запускай `cargo run -- --smoke-test`; пустые буферы и пустая сцена должны быть безопасны. Не добавляй бессодержательные тесты для правок документации.

Перед пересборкой проверь, не запущен ли старый exe: Windows блокирует замену исполняемого файла. Если для применения изменений нужен перезапуск, сообщи об этом пользователю; предпочитай штатное закрытие окна. Не закрывай приложение без необходимости.
